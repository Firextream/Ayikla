# Ayikla 1.5.0b1 · visual polish

- Start cards wrap body text without clipping at 100%, 125% and 150% DPI.
- The header groups brand/shoot on the left and aligned menus on the right.
- One top-right progress line and a two-row footer leave more room for the photo.
- Instructions move to Help; ignored helper-file counts move to Folders.
- Fit previews have 16 px margins; burst overlays anchor to the displayed image.
- Burst compare adds a 2 px keeper border and local number badges. Buttons have
  consistent height and spacing. Disabled text buttons meet the requested 3:1
  contrast. UI typography uses 12 / 13 / 15 / 20 px.

Behavior, shortcuts, photo operations, journals and undo stay unchanged. Existing
background preloading of next two / previous one photos is verified, including
worker-thread decoding and immediate forward/backward cache hits.

On the same generated 24 MP JPEG dataset, preloaded Next median/P95 is
4.24/4.90 ms versus 4.48/6.45 ms in 1.4. Cleared-cache median remains about
104 ms. See the [method and raw data](../benchmark/navigation-1.5.md) and
[DPI comparisons](../polish-1.5/README.md).

This beta is built locally. No tag, push or publication is implied by packaging.
