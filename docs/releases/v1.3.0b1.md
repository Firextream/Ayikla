# Ayikla 1.3.0b1 · local beta candidate

- B opens synchronized 2-up / 4-up burst comparison. Number keys select the
  keeper; Shift+Enter applies one journaled group decision. Paging covers the
  whole burst, and one Z restores every previous location after restart.
- Settings enables Lightroom XMP sidecars by default. Existing packets are
  backed up; only rating/pick values change. Other metadata stays intact.
- Standalone JPEG/TIFF film scans use the same decisions and undo. TIFF preview
  supports 16-bit grayscale and the existing Color ideas workflow.
- `02_edit/ayikla_picks.json` provides schema 1 metadata and palettes for Yazı
  or other image adders. See [the schema](../picks-schema.md).

The journal still reads older v1 records and adds `burst`, `picks_refresh`,
generated `write` operations and `applied` operation checkpoints. Once a shoot
uses these records, open it with 1.3 or later; an earlier app will stop on
unknown records rather than reinterpret them. Keep the archive and journal.

Large TIFF codecs can require full source memory before preview reduction.
XMP compatibility is verified using generated Lightroom-style packets; a live
Lightroom installation is not part of automated verification. Classic 13.2+
supports XMP flags; standalone JPEG/TIFF sidecar behavior varies by editor.

This candidate is built locally. No GitHub release, tag or push is authorized
by building it.
