# Ayikla 1.2.0b1 · Color ideas and more cameras

Download **Ayikla-1.2.0b1-Windows-x64.zip**, extract the entire archive, then run `Ayikla/Ayikla.exe`. No Python installation needed. Start with a separate copy of a small shoot.

- **Color ideas in round 2 (C):** filter by a dominant tone and 15/30/50% frame coverage, or find similar palettes to the current frame. Up to 24 matches with thumbnails and color swatches. Click a result, then E to pick it for editing; no automatic decisions.
- **More cameras:** Fujifilm RAF, Sony ARW/SRF/SR2, Olympus ORF, Canon CR3/CR2/CRW, Nikon NEF/NRW, Panasonic/Leica RW2/RWL, Pentax PEF, Samsung SRW and DNG. Requires a same-stem JPG/JPEG; RAW files are paired, not decoded.
- Local scaled JPEG analysis, cached descriptors and cancellation when closing the panel. Unreadable files are skipped and reported in the summary.
- File safety is unchanged: journal first, no overwriting, no photo deletion, persistent exact-path undo. Existing shoot folders and journals remain compatible.

Color matches are approximate and do not rate photographic quality. RAW-only, HEIC and automatic Lightroom import are not supported. This is an unsigned Windows x64 beta; real-camera/model and ICC accuracy still need field testing.
