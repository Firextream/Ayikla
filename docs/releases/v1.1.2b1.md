# Ayikla 1.1.2b1 · English photo club beta

A keyboard-first Windows app for culling Canon JPG/JPEG + CR3 shoots in two rounds.

## Download and run

Download **`Ayikla-1.1.2b1-Windows-x64.zip`** from Assets below. The “Source code” archives are not the runnable app.

Extract the entire ZIP → `Ayikla/Ayikla.exe` → **Open folder**. No Python installation needed. Keep `_internal` next to the executable. Start with a separate copy of 20–50 photo pairs. `GETTING_STARTED.md` inside the package is the quick guide.

## What's included

- **English throughout:** controls, help, status messages, EXIF labels, summaries and actionable errors.
- **Keep / Reject:** Enter moves JPG+CR3 to `01_secilen`; X / Delete moves them to `_red`. No permanent deletion.
- **Edit picks:** M switches rounds; E copies the pair to `02_edit` for Lightroom. E again removes the pick and archives copies without deleting them.
- **Persistent undo:** Z restores exact paths, including after reopening. Existing destinations are never overwritten.
- 100% zoom and pan, EXIF overlay, filmstrip, burst hints, recent folders and direct Explorer access.
- macOS `._` and hidden/system helpers are ignored. A corrupt JPEG can still be kept/rejected.
- Existing folder names and journal format are preserved. Compatibility with a journal produced by the previous Turkish build is tested.

## Beta limits

**135 tests passed.** The packaged app and the app extracted from the ZIP were verified with generated JPEGs and dummy CR3 files on Windows 11 x64. Other computers, high DPI/multiple monitors, real card disconnection and ICC accuracy still need field testing. This package is unsigned; Windows may warn. Do not disable security software; report the warning if it will not open. RAW images are not decoded and Lightroom import is manual.
