# Ayikla 1.6.0b1

Changes since 1.2.0b1:

- **Burst compare (B):** compare two or four frames at a time, choose a keeper, then confirm the entire burst with Shift+Enter. One Undo restores the group.
- **Lightroom XMP sidecars:** write ratings and Pick/Reject flags, preserve existing metadata, and restore the previous sidecar on Undo.
- **Film scans and TIFF:** cull standalone JPEG and TIFF scans alongside RAW+JPEG pairs, including scans without EXIF.
- **Card import (Ctrl+I):** copy into a dated shoot folder with size and SHA-256 verification, duplicate detection and persistent Undo.
- **Contact sheets:** export round 2 edit picks as a JPEG grid with an optional PDF copy.
- **Resume by capture time:** reopen at the saved photo, or the nearest undecided capture time if it moved or was renamed.
- **Progress line:** see decided, kept and rejected counts plus an estimated remaining time after ten session decisions.
- **Arrow-key choice:** select Fast culling (← Reject, → Keep) or Browse first (← Previous, → Next) on first launch or in Settings.
- **Real Undo / Previous / Next:** undo file decisions across restarts, or browse without making a decision using dedicated controls.
- **Clear Reject key label:** Fast culling shows **Reject · ←**; Browse first shows **Reject · X**. X / Delete remain Reject shortcuts in both modes.

[Download the Windows x64 ZIP](https://github.com/Firextream/Ayikla/releases/download/v1.6.0b1/Ayikla-1.6.0b1-Windows-x64.zip), extract the entire archive, then run `Ayikla/Ayikla.exe`. No Python installation needed.
